Veille technologique

La décompilation de jeux vidéo

C’est quoi ? Un jeu est livré en code illisible. La décompilation permet de retrouver un code lisible pour le garder, le modifier ou le jouer sur PC.

Ce que j’ai retenu en 2026 :

  • L’IA a rendu ça beaucoup plus rapide. Le site decomp.dev a fermé son classement public.
  • Les ports PC se multiplient, comme Dusklight pour Twilight Princess.
  • Nintendo serait derrière le retrait de quatre projets de ports.

Outils : Ghidra, IDA, GitHub.

Où je cherche : Time Extension, Kotaku, GitHub et Reddit.

À retenir : la décompilation est utile pour préserver les jeux, mais elle pose un problème légal.
